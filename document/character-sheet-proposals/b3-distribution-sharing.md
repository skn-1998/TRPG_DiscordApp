# 案B3: 配布・共有エコシステム設計（横断）

> **分類**: B系（横断コンポーネント。A系のどれを選んでも必要）
> **ステータス**: 案出し（未決定）
> **最終更新**: 2026-07-06

## 一言でいうと

テンプレートを「**作る → 公開する → 見つける → 取り込む → 派生させる**」の一連で回すための配布設計。
フロントのギャラリー mock（Fuse.js 検索・JSON import/export・`mock.template-gallery.tsx`）を実サービス化する。

## ライフサイクルと公開範囲

```
draft（作者のみ編集可）
  → published（version ごとに不変・semver）
  → deprecated（新規取り込み不可・既存キャラは動き続ける）
```

- **published version は不変**を基本とする（取り込んだ側のキャラが作者の後編集で壊れない、が配布の信頼の土台）。
  誤字修正レベルの patch を許すかは要判断（未決事項）
- visibility: `private` / `unlisted`（URL を知っている人のみ）/ `public`
  — phase0 §4.1.3 の `CharacterSheetTemplate.visibility` と同じ 3 値
- **fork**: `forkedFrom: { templateId, version }` の系譜を保持。配布物の由来表示と、
  「有名シートの派生」を辿れるようにする（TRPG 界のハウスルール文化と親和）

## 発見・取り込み

- **ギャラリー**: gameSystemId / タグ / 作者 / 人気（DL 数・使用キャラ数）で検索。
  まずサーバー側の単純フィルタ＋フロント Fuse.js 併用で開始し、必要になったら全文検索を検討
- **取り込み動線**:
  - 「このテンプレートでキャラ作成」1 クリック（→ B2 のインスタンス化フロー）
  - JSON import/export（フロント実装済みの形式を後方互換で維持）
  - unlisted の URL / 共有コード
- **バンドル配布（発展案）**: テンプレート単体でなく
  「テンプレート＋チャットパレット定義（`/user-dice` 連携）＋Discord ボタン既定（B4 の注釈）」を
  1 パッケージで配る。**「シートを入れたら Discord の卓 UI ごと整う」**は本アプリ固有の差別化になる

## 安全性・運用（配布物＝信頼できない入力）

- 式・参照表・ラベル文字列はすべて untrusted:
  - 式・テーブル → B1 の評価器サンドボックス（eval 禁止・上限つき）で扱う
  - ラベル・説明文 → sanitize（`characterTemplate/AI.security.md` の方針を継承。XSS）
  - サイズ上限: fields 数・式長・テーブル行数・JSON 全体サイズ
- モデレーション最小セット: 通報 → 運営非公開化。公開時の機械チェック（構文検証・サイズ・NG ワード）は同期実行
- **ライセンス / クレジット欄**: 配布文化（版権システムの用語・数値の扱い）への配慮として、
  作者記名と利用条件のフィールドを最初から持つ。**版権システムの技能名・データをどこまで公開テンプレートに
  許すかは運用ポリシーとして別途決める**（システムによっては二次利用ガイドラインあり）
- 外部互換（将来・別 adapter）: キャラクター保管所・ココフォリア等からの import は需要が大きいが、
  **内部正本フォーマットとは分離した adapter** として実装し、正本仕様を外部都合で歪めない

## API・認証まわり

- 現状の API はほぼ全て JwtAuthGuard。public ギャラリーの**未認証閲覧**を許すなら、
  read 系エンドポイントの認可設計（ゲスト read / レート制限）が新規論点になる
- 人気指標（使用キャラ数）の集計は character ドメインへの**逆依存を作らない**:
  `character.created`（テンプレ利用）等のイベントを template ドメイン側が購読してカウンタ更新する方式を推奨

## 決めるべきこと

1. published の不変性ポリシー（完全不変 / patch のみ許可）
2. 未認証閲覧の可否とレート制限
3. バンドル配布をどの段階で入れるか（B4 の注釈仕様が固まってから）
4. 版権データの公開ポリシー（ガイドライン文書と通報カテゴリ）
5. 人気指標の初期セット（DL 数だけで始めるのが安全）
