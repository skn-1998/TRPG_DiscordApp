# Context-Qualified Language Contract

Apply this contract only to material terms in the requested scope.

## Evidence Labels

- `supplied`: stated in the request or an identified authoritative artifact;
- `observed`: directly present in domain examples, documents, model, or code;
- `inferred`: derived from supplied or observed evidence;
- `unknown`: not established.

Do not convert a frequent expression, current code name, or one person's usage into approved domain language.

## Term Record

```text
Expression:
Scoped context:
Actor and purpose relevance:
Meaning in use:
Rules or distinctions carried:
Example or counterexample: [only when it resolves a material ambiguity]
Evidence and provenance:
Status: [evidence-supported / provisional / unresolved / contradicted]
Open disagreement or unknown:
```

The status reports evidence quality, not organizational approval.

## Comparison Record

Compare expressions only when they can materially confuse the requested decision.

```text
Expressions and occurrences:
Scoped context or contexts:
Finding: [overloaded-term / synonym-or-inconsistency / contradiction / distinct-and-intentional / unresolved]
Meaning, purpose, and rule comparison:
Evidence:
Consequence for the requested decision:
```

Use these proportional rules:

- same expression plus materially different meaning, purpose, rules, or applicability indicates overload;
- different expressions plus materially equivalent meaning and rules in one context indicates a synonym or inconsistency candidate;
- different contexts may retain different meanings; record a correspondence only when an evidenced interaction requires one;
- a conversation/model/code mismatch is an alignment gap, not an automatic rename.

## Candidate Shared Expression

```text
Candidate expression:
Scoped meaning and rules:
Alternatives considered:
Evidence:
Affected artifacts or conversations:
Status and unresolved authority:
```

Do not invent an approver. If supplied policy names a decision authority, preserve it as provenance; otherwise leave authority unknown.

## Status Notes

Apply the completion rule in `SKILL.md`. A supported report may still contain unresolved terms; unresolved evidence is not the same as an incomplete reporting artifact.
