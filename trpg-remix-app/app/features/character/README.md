# キャラクターシートエディタ機能

## 概要

汎用的なTRPGキャラクターシートを作成・編集できる機能を実装しました。Excelのような表形式でキャラクターシートのレイアウトを作成し、セルの名前や計算式を設定できます。

## 機能

### 1. キャラクターシートテンプレート作成
- Excelのような表形式でキャラクターシートのレイアウトを作成
- セルの名前設定（例：STR、INT、HP）
- セルの入力値設定（例：1d6、3d6*5）
- セル参照機能（例：[STR]×5でSTRの値を参照）

### 2. 計算式エンジン
- ダイス計算（1d6、2d10など）
- セル参照（[セル名]）
- 基本的な数式計算（+、-、*、/）
- 循環参照の検出

### 3. レイアウトエディタ
- グリッド形式の編集インターフェース
- セルの結合・分割機能
- カスタムスタイル（背景色、文字色など）
- プレビュー機能

## 使用例

### 1. クトゥルフ神話TRPGのキャラクターシート例

```typescript
const cthulhuTemplate: CharacterSheetTemplate = {
  id: 'cthulhu_basic',
  name: 'クトゥルフ神話TRPG 基本シート',
  gameSystemId: 'Cthulhu',
  cells: [
    {
      id: 'str_cell',
      name: 'STR',
      value: '3d6*5',
      type: 'stat',
      row: 0,
      col: 0
    },
    {
      id: 'hp_cell',
      name: 'HP',
      value: '([CON]+[SIZ])/10',
      type: 'calculated',
      row: 1,
      col: 0
    }
  ]
}
```

### 2. 計算式の例

- `1d6` - 1個の6面ダイスを振る
- `3d6*5` - 3個の6面ダイスを振って5倍する
- `[STR]×5` - STRセルの値を5倍する
- `([CON]+[SIZ])/10` - CONとSIZを足して10で割る

## アクセス方法

1. `/character/sheet-editor` にアクセス
2. 「新しいテンプレート作成」ボタンをクリック
3. テンプレートの基本情報を入力
4. グリッドタブでセルを配置・編集
5. プレビュータブで結果を確認
