# TRPGキャラクターシートエディタ - 実装概要

## 実装完了項目

### 1. 型定義システム
- **ファイル**: `trpg-remix-app/app/types/characterSheet.ts`
- **機能**: キャラクターシートテンプレートの完全な型定義
- **主要な型**:
  - `CellData`: セルの情報（名前、値、計算式、位置、スタイル）
  - `CharacterSheetTemplate`: テンプレート全体の構造
  - `CharacterSheetInstance`: 実際のキャラクターシートインスタンス
  - `CellReference`: セル参照機能用の型

### 2. 計算式エンジン
- **ファイル**: `trpg-remix-app/app/utils/formulaEngine.ts`
- **機能**: 高度な計算式処理システム
- **主要機能**:
  - ダイス計算（1d6、2d10など）
  - セル参照（[STR]、[CON]など）
  - 基本数式演算（+、-、*、/、括弧）
  - 循環参照検出
  - 安全な式評価

### 3. キャラクターシートエディタ
- **ファイル**: `trpg-remix-app/app/features/character/components/characterSheetEditor.tsx`
- **機能**: 視覚的なシートエディタ
- **主要機能**:
  - グリッドベースのレイアウト
  - セルの追加・編集・削除
  - リアルタイムプレビュー
  - 計算式の結果表示
  - カスタムスタイル設定

### 4. エディタページ
- **ファイル**: `trpg-remix-app/app/routes/character+/sheet-editor.tsx`
- **機能**: エディタのメインインターフェース
- **主要機能**:
  - テンプレート一覧表示
  - テンプレートの作成・編集
  - プレビュー機能

### 5. テストスイート
- **ファイル**: `trpg-remix-app/app/utils/formulaEngine.test.ts`
- **機能**: 計算エンジンの包括的テスト
- **テスト内容**:
  - ダイス計算の正確性
  - セル参照の解決
  - 循環参照の検出
  - 複雑な計算式の評価

## 実装例: クトゥルフ神話TRPGキャラクターシート

### サンプルテンプレート
```typescript
const cthulhuTemplate: CharacterSheetTemplate = {
  id: 'cthulhu_basic',
  name: 'クトゥルフ神話TRPG 基本シート',
  gameSystemId: 'Cthulhu',
  version: '1.0',
  author: 'System',
  description: 'クトゥルフ神話TRPGの基本的なキャラクターシート',
  gridSize: { rows: 12, cols: 6 },
  cells: [
    // 基本能力値
    {
      id: 'str_cell',
      name: 'STR',
      value: '3d6*5',
      type: 'stat',
      row: 1,
      col: 0
    },
    {
      id: 'con_cell',
      name: 'CON',
      value: '3d6*5',
      type: 'stat',
      row: 1,
      col: 1
    },
    // 計算値
    {
      id: 'hp_cell',
      name: 'HP',
      value: '([CON]+[SIZ])/10',
      type: 'calculated',
      row: 4,
      col: 0
    },
    {
      id: 'mp_cell',
      name: 'MP',
      value: '[POW]/5',
      type: 'calculated',
      row: 4,
      col: 1
    },
    {
      id: 'san_cell',
      name: 'SAN',
      value: '[POW]',
      type: 'calculated',
      row: 4,
      col: 2
    }
  ]
}
```

### 計算式の例
| 計算式 | 説明 | 結果例 |
|--------|------|--------|
| `1d6` | 1個の6面ダイスを振る | 1-6 |
| `3d6*5` | 3個の6面ダイスを振って5倍 | 15-90 |
| `[STR]×5` | STRセルの値を5倍 | STR=15の場合75 |
| `([CON]+[SIZ])/10` | CONとSIZを足して10で割る | CON=70,SIZ=60の場合13 |
| `([POW]-[SAN])*2` | POWからSANを引いて2倍 | POW=55,SAN=45の場合20 |

## 技術仕様

### アーキテクチャ
- **フロントエンド**: React + TypeScript
- **UIライブラリ**: Mantine
- **状態管理**: React Hooks
- **計算エンジン**: カスタム実装（安全な式評価）
- **データ形式**: JSON

### セキュリティ
- 計算式の実行にはFunction()を使用（evalより安全）
- 入力値の検証
- 循環参照の検出と防止
- 不正な計算式の拒否

### パフォーマンス
- 効率的な再計算アルゴリズム
- 変更があった場合のみ再計算
- 最大10回の反復計算で収束保証

## 使用方法

### 1. エディタへのアクセス
```
/character/sheet-editor
```

### 2. テンプレート作成手順
1. 「新しいテンプレート作成」をクリック
2. 基本情報を入力
3. グリッドタブでセルを配置
4. 各セルの名前と計算式を設定
5. プレビューで結果を確認
6. 保存

### 3. セルの設定項目
- **名前**: セル識別子（STR、INT、HPなど）
- **値**: 計算式または固定値
- **タイプ**: stat、skill、calculated など
- **位置**: 行・列座標
- **スタイル**: 背景色、文字色など

## 利点

1. **汎用性**: 任意のTRPGシステムに対応
2. **柔軟性**: 自由なレイアウト設計
3. **自動化**: 計算の自動化でミス防止
4. **効率性**: 素早いキャラクター作成
5. **拡張性**: 新機能の追加が容易

## 結論

このキャラクターシートエディタは、TRPGプレイヤーとGMが自由にキャラクターシートをカスタマイズできる強力なツールです。計算式エンジンによる自動計算と、視覚的なエディタによる直感的な操作により、従来の固定フォーマットの制約を超えた柔軟なキャラクター管理が可能になります。
