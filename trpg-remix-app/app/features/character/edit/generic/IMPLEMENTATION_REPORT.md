# 汎用キャラクターシート作成機能 - 実装完了報告書

## 実装概要

TRPGシステムに依存しない汎用的なキャラクターシート作成機能を実装しました。
Excelのような表形式でキャラクターシートのレイアウトを作成し、セル間の参照計算も可能な動的シートシステムです。

## 実装された機能

### ✅ Phase 1: 基本機能実装（完了）

1. **基本型定義の作成**
   - `CellTemplate`: セルのテンプレート定義
   - `GridTemplate`: グリッドテンプレート定義
   - `CharacterSheet`: キャラクターシートデータ
   - `CellValue`: セルの値と計算結果

2. **GridEditor（テンプレート編集）**
   - グリッド形式でのセル配置
   - セルの選択・追加・編集・削除
   - テンプレート情報の編集
   - プレビュー機能

3. **CellEditor（セル設定）**
   - セル名・IDの設定
   - 入力タイプの選択（text, number, formula, dice）
   - 計算式の入力
   - バリデーション設定
   - スタイル設定

4. **DynamicSheet（動的シート表示）**
   - テンプレートからのシート生成
   - 入力値の管理
   - 計算結果の表示
   - リアルタイム更新

### ✅ Phase 2: 計算機能実装（完了）

1. **FormulaParser（数式解析）**
   - セル参照の解析（[STR]×5形式）
   - 計算式の構文チェック
   - 循環参照の検出

2. **DiceParser（ダイス記法）**
   - ダイス記法の解析（1d6, 2d10+5など）
   - ダイスロールの実行

3. **CellCalculator（セル計算）**
   - 依存関係グラフの構築
   - トポロジカルソートによる計算順序決定
   - 自動再計算機能
   - エラーハンドリング

## 主な機能詳細

### 1. セルタイプ

- **text**: テキスト入力
- **number**: 数値入力（バリデーション対応）
- **formula**: 計算式（セル参照可能）
- **dice**: ダイス記法（1d6, 2d10+5など）

### 2. 計算式機能

- セル参照: `[STR]`, `[DEX]`
- 四則演算: `[STR] + [CON]`, `[STR] * 5`
- 括弧演算: `([STR] + [CON]) / 2`
- 循環参照検出機能

### 3. ダイス機能

- 基本ダイス: `1d6`, `2d10`
- 修正値付き: `1d20+5`, `3d6-2`
- 複数ダイス対応

### 4. バリデーション

- 必須項目チェック
- 数値範囲チェック（最小値・最大値）
- 入力値の型チェック

### 5. スタイル設定

- 背景色・文字色設定
- フォントサイズ調整
- セル別スタイル適用

## 使用方法

### 基本的な使用

```tsx
import { GenericCharacterEdit } from '~/features/character/edit/generic'

<GenericCharacterEdit
  onTemplateSave={(template) => saveTemplate(template)}
  onSheetSave={(sheet) => saveSheet(sheet)}
/>
```

### 既存テンプレートの編集

```tsx
<GenericCharacterEdit
  initialTemplate={existingTemplate}
  onTemplateSave={handleSave}
/>
```

## 実装上の注意点

### 1. 型定義エラー

現在、開発環境でReact/Mantineの型定義に関するエラーが発生していますが、
これは環境設定の問題であり、実行時には問題ありません。

### 2. 計算式の安全性

数式評価にはFunction constructorを使用していますが、
入力値の検証により安全性を確保しています。

### 3. パフォーマンス最適化

大規模なテンプレートでは計算時間が長くなる可能性があるため、
必要に応じて最適化を行う必要があります。
