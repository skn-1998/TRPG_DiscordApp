# キャラクターシートテンプレート機能 — UI 設計（完全刷新版）

> **正本注記（2026-08-04）**: 本文は V2 世代（diceFormula・固定4タブ）の記述。現行 V3 エディタの正本は
> `document/character-sheet-proposals/design-v1-ui.md` と実装（TemplateEditorV3/TemplatePreviewV3/TemplateListV3）。

## 画面構成

### エディタ画面

**目的**: テンプレートの作成・編集

#### タブ切替UI

- 4つのタブ: `basic` / `status` / `parameter` / `skill`
- Mantine `Tabs` コンポーネント使用
- 各タブに独立したグリッドレイアウト

#### フィールドパレット

フィールド追加UI（タブごとに表示）

- 基本: Text / Textarea / Number / Select / Checkbox
- 計算: Computed（式入力）
- ロール: Roll（ダイス式入力）

#### グリッド配置エディタ

- 12カラムグリッドシステム
- 行追加/削除
- 列幅設定（1～12）
- フィールド割当（ドロップダウン or リスト選択）
- MVP: ドラッグ&ドロップなし（上下移動ボタンのみ）

#### フィールド編集フォーム

各フィールド種別の属性編集：

- **共通**: id, label, description, required, tab
- **Number**: min, max
- **Select**: options（ラベル・値ペア）
- **Textarea**: rows
- **Computed**: formula（式入力、構文ハイライト）
- **Roll**: diceFormula（ダイス式入力）

#### 検証結果表示

- エラー一覧をリスト表示
- 重複ID、循環参照、構文エラーを色分け
- エラー箇所へのジャンプリンク

#### 保存/読み込み

- ローカル保存（localStorage）
- インポート/エクスポート（JSON）
- 自動保存（オプション）

### プレビュー画面

**目的**: テンプレートから生成されるキャラクターシート入力フォームの確認

#### タブ切替

- エディタと同じタブ構造
- グリッドレイアウトを再現

#### フィールド表示

- **Text / Textarea**: `TextInput` / `Textarea`
- **Number**: `NumberInput`
- **Select**: `Select`
- **Checkbox**: `Checkbox`
- **Computed**: 読み取り専用 `TextInput`（計算結果表示）
- **Roll**: `NumberInput` + ロールボタン

#### ロールボタン

- ダイス式を含むフィールドの右側に配置
- アイコン: 🎲（ダイスアイコン）
- クリックでダイスロール実行、値を上書き
- ロール後も手動編集可能

#### タブ一括ロール

- 各タブに「全てロール」ボタン
- タブ内の全ロールフィールドを一括実行
- ローディング状態表示

#### 依存フィールドの再計算

- 値変更時に依存グラフを辿って自動再計算
- 計算中のローディング表示（重い場合）

#### 入力データ表示

- 現在の入力値をJSON形式で表示（デバッグ用）
- 折りたたみ可能

### ギャラリー画面

**目的**: 公開テンプレートの閲覧・検索

#### 検索UI

- `TextInput` + Fuse.js
- タグフィルタ（複数選択）
- ソート（名前、作者、バージョン、作成日）

#### カード一覧

- `Card` コンポーネント
- 表示情報: 名前、作者、タグ、バージョン、作成日
- クリックで詳細表示 or エディタで開く

#### 詳細表示

- メタ情報
- フィールド一覧
- プレビュー
- インポートボタン

### マッピング画面（MVP外、ドキュメント化のみ）

**目的**: テンプレートフィールドと`character`型のパスを紐付け

#### UI案

- 左: テンプレートフィールド一覧
- 右: `character`型のパス候補
- ドラッグ&ドロップ or 手動入力で紐付け
- 保存（localStorage）

## アクセシビリティ

### ラベル・説明

- 全フィールドに`label`属性
- `description`を`aria-describedby`で関連付け
- `required`フィールドに視覚的・音声的インジケータ

### キーボード操作

- Tab順序の最適化
- Enterでフォーム送信
- Escapeでモーダル閉じる
- 矢印キーでグリッド移動（将来）

### カラーコントラスト

- WCAG AA準拠
- エラー表示は色だけでなくアイコンも併用

## エラーハンドリング

### 入力検証エラー

- インライン表示（フィールド下部）
- エラーメッセージは具体的に（例: 「IDが重複しています: pow」）

### 保存/読み込みエラー

- `Notification`で通知
- エラー詳細をログ出力

### ロールエラー

- ダイス式の構文エラー
- 範囲外の値（例: `[0d6]`、`[1d0]`）
- エラー時はフィールドを空欄のまま、エラーメッセージ表示

### 計算エラー

- 未定義参照、循環参照
- ゼロ除算
- エラー時は`Error`と表示、ツールチップで詳細

## レスポンシブデザイン

### デスクトップ（≥768px）

- エディタとプレビューを左右2カラム表示
- グリッド12カラム

### タブレット（≥640px, <768px）

- エディタとプレビューを上下表示
- グリッド12カラム（折り返し）

### モバイル（<640px）

- エディタとプレビューをタブ切替
- グリッド単カラム（全幅）

## パフォーマンス

### 式評価

- 依存グラフで変更影響範囲を限定
- 不要な再計算を防ぐ
- 重い計算は`useMemo`でキャッシュ

### ロール実行

- 非同期処理（Promise）
- 一括ロール時はバッチ処理

### UI更新

- React.memoで不要な再レンダリング防止
- 仮想スクロール（フィールド数が多い場合、将来対応）
