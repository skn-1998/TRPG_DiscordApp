# キャラクターシートテンプレート機能 — API 設計（将来サーバー統合、完全刷新版）

当面はフロントエンドのみ（ローカル/モック）。以下はTRPG-SERVER統合時のAPI想定。

## エンドポイント（案）

### テンプレートCRUD

- **POST `/templates`**: テンプレート作成（ドラフト）
- **PUT `/templates/:id`**: テンプレート更新
- **GET `/templates/:id`**: 単体取得（公開/ドラフト権限）
- **DELETE `/templates/:id`**: 削除（所有者のみ）

### 検索・ギャラリー

- **GET `/templates`**: クエリ検索（キーワード/タグ/作者/ソート）
- **GET `/gallery/templates`**: 公開ギャラリー

### 公開・バージョン

- **POST `/templates/:id/publish`**: 公開/非公開切替、バージョン発行
- **GET `/templates/:id/versions`**: バージョン一覧
- **GET `/templates/:id/versions/:version`**: 特定バージョン取得

### バリデーション

- **POST `/templates/validate`**: テンプレートバリデーション（式構文、循環参照、ダイス記法）

## モデル（サーバー側）

### Template

```ts
{
  id: string
  name: string
  version: string // semver
  authorId: string
  tags: string[]
  fields: Field[] // 式、ダイスを含む
  layout: TabLayout[]
  status: 'draft' | 'published'
  schemaVersion: number // 現在: 2
  createdAt: Date
  updatedAt: Date
  publishedAt?: Date
}
```

### TemplateVersion

```ts
{
  templateId: string
  version: string
  changelog: string
  fields: Field[]
  layout: TabLayout[]
  createdAt: Date
}
```

## 権限/認可

- **作成/更新/削除**: 所有者のみ
- **公開切替**: 所有者と管理者のみ
- **閲覧**: 公開テンプレートは全員、ドラフトは所有者のみ

## バリデーション（サーバー側）

### 式エンジン

- **構文チェック**: 未定義参照、演算子ミス
- **循環参照検出**: 依存グラフでDFS
- **サンドボックス実行**: 安全な評価器で悪意あるコード実行を防ぐ
- **実行時間制限**: 無限ループ防止（タイムアウト）

### ダイスロール

- **記法チェック**: `[NdM]`, `[NdM+K]`, `[NdM-K]` 形式
- **範囲チェック**: N≥1, M≥2, |K|≤10000
- **実行制限**: 一度に振れるダイス数上限（例: 100個）

### XSS/注入対策

- **フィールド値サニタイズ**: label, description, options.label
- **式評価の安全性**: evalは使わない、ホワイトリスト方式
- **ダイス式**: 正規表現で厳密に検証

## モデレーション

- 不適切コンテンツ報告API
- 管理者レビュー
- 公開取り消し（非公開化）
- ユーザーペナルティ（一時停止、永久停止）

## レート制限/監査

### レート制限

- 書き込み操作: 100 req/hour/user
- 検索: 1000 req/hour/user
- バリデーション: 500 req/hour/user

### 監査ログ

- 作成/更新/削除
- 公開/非公開切替
- バージョン発行
- 不適切報告

## セキュリティ

### 式評価のサンドボックス

- evalは使わない
- ホワイトリスト方式（許可された関数・演算子のみ）
- AST（抽象構文木）ベースの評価器
- 実行時間制限

### ダイスロール

- 正規表現で厳密に検証
- ランダム性の担保（crypto.randomInt使用）
- シード保存（再現性確保、オプション）

### 依存ライブラリ

- 定期アップデート
- 既知脆弱性監視（Dependabot, Snyk等）

## 互換性/移行

### schemaVersion管理

- 現在: 2（式＋ダイス対応版）
- 旧: 1（基本フィールドのみ）

### マイグレーション

- 自動マイグレーションは行わない
- 非互換テンプレートはエラー表示
- 手動更新を促す
- 移行ガイドを提供

### バージョニング

- semverに準拠
- メジャー: 非互換変更
- マイナー: 機能追加（後方互換）
- パッチ: バグ修正
