# TRPG-SERVER docs

TRPG-SERVER の補助ドキュメント置き場。

作業時の正本は引き続き次を優先する。

- `AI.md`
- `src/ARCHITECTURE.md`
- 対象領域の `DESIGN.md` / `README.md`
- `AI.refactor.md`

## ディレクトリ

| path        | 役割                                         |
| ----------- | -------------------------------------------- |
| `guides/`   | 現役だが root 直下に置く必要が薄い補助ガイド |
| `history/`  | 旧調査メモ、撤回済み提案、履歴として残す資料 |
| `refactor/` | 完了済みリファクタ計画・監査メモ             |
| `reviews/`  | Claude/Codex による棚卸し・レビュー成果物    |
